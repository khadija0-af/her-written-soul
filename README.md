# Her Written Soul ✍️

A creative poetry and writing website designed to showcase poems and written pieces in a visually engaging web experience.

## ✨ Features

* Elegant and creative user interface
* Poetry and creative writing sections
* Responsive web design
* Clean typography and visual presentation

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 Purpose

This project was created to combine creative writing with web development and practice designing an engaging digital experience around written content.
